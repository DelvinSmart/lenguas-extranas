# Lenguas extrañas?

Mapa para exponer el tema "Lenguas extrañas?", punto por punto.

- `index.html`: la página.
- `css/styles.css`: colores, letras y diseño.
- `js/contenido.js`: el texto de cada rama y cada punto (aquí se cambia el contenido).
- `js/mapa.js`: dibuja el mapa y el panel de lectura.
- `js/audio.js`: lee en voz alta el punto abierto, o todo desde ahí (botones Escuchar).
- `descargas/Mapa-Lenguas-extranas.pdf`: versión en PDF para leer sin internet (fondo negro, letras blancas).
- `pdf/`: la página que arma el PDF. Para volver a generarlo después de cambiar el texto: `./pdf/generar-pdf.sh`

Para verlo en tu computadora, abre `index.html` en el navegador.
